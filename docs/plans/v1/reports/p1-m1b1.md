## Interface choices the plan left open

1. (revised after review) The journal assigns `write_seq`: `try_reserve(kind, blocks)` returns a `Slot` holding a fresh global seq (registered in flight) or `Full`/`NoSpace` with no seq consumed; `append(slot, lba, data)` is infallible except a fatal `Io`. `RecordInfo` replaces format's `RecordHeader` (the journal fills `gen`/`off`). `JournalLoc` addresses record **data**.
2. Read ownership: `submit_read(loc, buf: Vec<u8>, token)`; the buffer comes back in `JournalCompletion::Read`. Appends complete as `JournalCompletion::Append {write_seq}`.
3. Group flush completes through a `FnOnce` callback (`FlushDone`), not a token poll, so no extra fd is needed. `Journal::open_lane(lane, WakeFd)` hands the queue wake fd to the lane (ring eventfd). Added `Journal::tail_after(cut)` (the engine cannot compute per-lane tails) and `fill()`.
4. Deferred READ completion needs the tag buffer: `Completer::tag_buf(tag)`; workers never touch it.
5. `CommitStore::delete(seq, chain_floor)` takes the authenticated floor from the caller (commits may be sealed, the store cannot read the tip). Added `set_aside(seq)` for `--truncate-tip`.
6. `read_extent` returns raw stored bytes; the tag/AEAD is verified once, by `ExtentCodec::open` (M7's gate line "every extent read verifies" is met by composing the two; M7 must not verify twice).
7. `ExtentCodec::open` takes `OpenExpect` with `OpenOutput::{Stored, Plaintext}`: compaction and dedup confirmation need the compressed payload, reads need plaintext. So M2 decompresses (it needs lz4/zstd dependencies; the skeleton lacks them: a `deps:` commit by M2).
8. `MapTxn` is a batch applied on `commit` and discarded on drop (atomic cut); `rehint` is evaluated at commit; `TxnReport` counts applied/skipped; `MapFull` from `set`. `walk_leaves_skipping(root, skip)` added (M17 rule 3 needs it); `NodeSource::load_node` (renamed to avoid clashing with `PackRead::read_node`).
9. Space: `reserve(kind, bytes, wake)` returns `Reserved | Parked(Waiter) | NoSpace`; `Waiter` is a concrete shared handle (grant/expire/cancel by the gate, `state()` polled by the engine, wake fd signalled). `tick()` expires waiters on the clock. `Headroom` is a pseudo-kind holding bounds; walk-through step list is in `space` docs. `SpaceGate: Ladder + SpaceEvents`.
10. `IdAllocator` (`allocate`, `high_water`, `observe`) and `VolumeDir::sweep_orphans(SweepRequest) -> SweepReport {highest_id_before, ..}` implement D17's allocator rule; `leftovers()/remove_leftovers()` for fsck.
11. `GcControl` (`run_pass`, `run_urgent`, `status`) is how the ladder's compact step and the `Gc` socket call reach the single coordinator thread; `Collector::{step, urgent, dry_run, stats}`.
12. `ctl`: envelope `{"v":1,"id":N,"method","params"}` / `{"v","id","ok":{"type":..}|"err":{code,message}}`; `Secret` is hex on the wire; requests `deny_unknown_fields`, responses tolerant; `Request::validate()` holds every bound; `ErrorCode::exit_code()` gives M13a's exit codes.
13. `crashpoint!`: two macro definitions selected by `cfg(feature)` inside iface (a `cfg!` in the expansion would test the user's crate). Registry via `inventory`, `LUNIX_CRASH_COUNT` + `dump_counts()` added so M15 can pick middle/last hits.
14. Contract macros expand thin `#[test]`s over ordinary generic functions plus `*Fixture` traits (crash/reopen hooks); optional leading module name.

## rust-skills conflicts

- `doc-all-public`/`lint-missing-docs`: public items are documented; `missing_docs` is not enforced as a lint (consistent with M1.A).
- `api-non-exhaustive`: `Error`, `ErrorKind`, `FrameError` are `non_exhaustive`; the protocol enums and plan-fixed enums (`IoOp`, `SpaceKind`) are closed on purpose.
- `err-no-unwrap-prod`/`expect`: the contract suites and trivial impls use `expect` as assertions (test code in a library module).
- `type-newtype-ids`: `Tag`, `QueueId`, `LaneId`, `Token`, `ChunkNo` are newtypes; `Waiter` is concrete rather than a trait (`trait-dyn-vs-generic`: one state machine both sides must agree on).
- `proj-feature-additive`: `crashpoints` is additive (registers and kills only when `LUNIX_CRASH_AT`/`LUNIX_CRASH_COUNT` is set).
