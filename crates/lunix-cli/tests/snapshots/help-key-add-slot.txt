Add a key slot

Usage: lunix key add-slot [OPTIONS] <NAME>

Arguments:
  <NAME>  The volume name

Options:
      --dir <DIR>                  The directory the volume was created in
      --socket <PATH>              The control socket of lunixd [default: /run/lunix/ctl.sock]
      --passphrase                 Use a passphrase. It is prompted on the terminal without echo, or read from --passphrase-fd; it is never taken from the command line or the environment
      --passphrase-fd <FD>         Read the passphrase from this file descriptor (implies --passphrase). The descriptor must be a file or a pipe; one trailing newline is removed
      --key-file <FILE>            The new slot's key file (a key-file slot instead of a passphrase slot)
      --unlock-key-file <FILE>     An existing key file that unlocks the volume
      --unlock-passphrase-fd <FD>  Read the existing passphrase that unlocks the volume from this descriptor
  -h, --help                       Print help
