List and change the key slots of a detached volume

Usage: lunix key [OPTIONS] <COMMAND>

Commands:
  ls        List the key slots (a plain volume has none)
  add-slot  Add a key slot
  rm-slot   Remove a key slot

Options:
      --socket <PATH>  The control socket of lunixd [default: /run/lunix/ctl.sock]
      --timeout <T>    How long to wait for the daemon's reply (500ms, 60s, 5m, 1h); attach and gc can be slow, so the default is generous [default: 10m]
  -h, --help           Print help
