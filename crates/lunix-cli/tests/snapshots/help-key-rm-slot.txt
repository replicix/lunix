Remove a key slot

Usage: lunix key rm-slot [OPTIONS] --slot <N> <NAME>

Arguments:
  <NAME>  The volume name

Options:
      --slot <N>                   The slot number from `key ls`
      --socket <PATH>              The control socket of lunixd [default: /run/lunix/ctl.sock]
      --dir <DIR>                  The directory the volume was created in
      --timeout <T>                How long to wait for the daemon's reply (500ms, 60s, 5m, 1h); attach and gc can be slow, so the default is generous [default: 10m]
      --unlock-key-file <FILE>     An existing key file that unlocks the volume
      --unlock-passphrase          Ask on the terminal for the existing passphrase that unlocks the volume (no echo)
      --unlock-passphrase-fd <FD>  Read the existing passphrase that unlocks the volume from this descriptor
  -h, --help                       Print help
